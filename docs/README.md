# Jigwright Documentation

Jigwright is a current-v3 repository workflow engine for well-intentioned AI
agents. It preserves governed planning, task execution, Git CAS, recovery,
provider/session orchestration, optional authorization, managed documents, and
archive correctness without carrying v1/v2 compatibility or consumer product
data.

- `docs/WORKFLOW.md` is the operator and contributor workflow guide.
- `docs/ROADMAP.md` records current migration and release priorities.
- `docs/DECISION-REGISTER.md` records accepted product-boundary decisions.
- `docs/CURRENT-V3-PARITY-LEDGER.md` keeps the frozen current-v3 denominator
  and its explicit live dispositions.
- `docs/CURRENT_AND_NEXT_STEPS.md` is the generated current handoff.
- `docs/architecture/` describes the package and engine boundaries.
- `openspec/specs/` contains normative product requirements.
- `openspec/changes/` contains governed current and archived change artifacts.

Archived change artifacts are immutable historical evidence. They do not
create runtime compatibility requirements for pre-current schemas.
